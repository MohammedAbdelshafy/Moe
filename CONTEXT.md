# Moe Workspace CONTEXT

One job: provide a home for the existing project folders and study notes until each has a confirmed owner and purpose.

## Inputs
- Current inventory: [projects](projects/) and [study-notes](study-notes/)
- Entry point: [README](README.md)
- Portfolio ownership map: [Jarvis ICM](https://github.com/MohammedAbdelshafy/jarvis-mbm/blob/feature/icm-portfolio-map/ICM/REPO_MAP.md)

## Process
1. Inspect a specific project folder or note before working on it.
2. Identify its intended user, output and current state.
3. Check for a canonical owner repo elsewhere in the portfolio.
4. Record dependencies and consumers before suggesting consolidation.
5. Do not rename or delete material during inventory.

## Output
A clear inventory and next-action recommendation for each meaningful subproject.

## Check
Every active subproject has a one-sentence purpose, owner, source of truth and next action. Until that exists, classify it as needs review rather than inventing a product.
