# Moe's Workspace CONTEXT

One job: keep personal project material and study notes easy to find without mixing their purpose or moving files without checking links.

## Inputs
- Project folders: [projects](projects/)
- Study notes: [study-notes](study-notes/)
- Portfolio route: [Jarvis ICM map](https://github.com/MohammedAbdelshafy/jarvis-mbm/blob/feature/icm-portfolio-map/ICM/REPO_MAP.md)

## Process
1. Choose whether the work belongs to a project or study note.
2. Read the relevant folder's README or current source before making changes.
3. Keep each project in a bounded folder with its own scope and checks.
4. Preserve existing paths until references have been checked.
5. Do not commit credentials or private personal data.

## Output
A navigable personal workspace with each project and study topic in its own clear home.

## Check
A new reader can identify where project code and study notes belong within one read. No private secrets or unneeded personal data enter version control.
